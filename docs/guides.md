# Guides - ML Intern Planner

ML Intern Planner turns a research goal into a practical brief with papers, datasets, model choices, compute assumptions, checkpoints, and deliverables.

## Write the starter prompt

Name the task, model family, data source, compute budget, metric, and review deadline.

## Package a training job

Include dataset version, config, baseline, metric, expected runtime, owner, and rollback criterion.

## Read the GitHub repo

Inspect official examples, supported surfaces, and what teams usually add around review and operations.
