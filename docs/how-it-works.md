# How It Works - ML Intern Planner

ML Intern Planner turns a research goal into a practical brief with papers, datasets, model choices, compute assumptions, checkpoints, and deliverables.

## Scope the research goal

State the task, deadline, data state, target model family, and expected artifact.

## Collect context

Identify papers, datasets, models, repos, docs, and Hub Spaces that shape the plan.

## Choose execution path

Pick fine-tune, evaluation, dataset work, or agentic pipeline based on bottleneck and compute budget.

## Ship the brief

Use the generated plan as a checklist for jobs, reviews, and deliverables.

## Pricing and Support

The public planner is useful before purchase; team plans standardize briefs, review gates, and research-ops workflow.
