# Features - ML Intern Planner

ML Intern Planner turns a research goal into a practical brief with papers, datasets, model choices, compute assumptions, checkpoints, and deliverables.

## Plain-English problem scoping

Turn a goal into task type, horizon, compute posture, output shape, and review needs.

## Research context pull

Keep papers, docs, datasets, models, repositories, and Hub surfaces in the same planning frame.

## Compute-spend decision support

Decide when a fine-tune, evaluation, dataset reshape, or agentic pipeline deserves compute.

## Execution review list

Generate checkpoints for dataset quality, baselines, metrics, job packaging, and deliverables.

## Hugging Face-aware links

Point users to the official repo, Space, Hub resources, and ML agent explorers.

## Team-readable briefs

Produce artifacts that survive beyond a chat transcript and can be reviewed by teammates.

## Pricing and Support

The public planner is useful before purchase; team plans standardize briefs, review gates, and research-ops workflow.
